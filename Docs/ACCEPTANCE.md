# v0.1 验收与下一步

## 自动验证

`swift test` 检查保底、重复转换、货币不足、建筑等级上限、编队、存档合法性、
攻击距离 / 冷却 / 连击、闪避保护、阵亡换人、三波胜利和帧时间边界。
`xcodebuild` 检查完整 iOS 应用编译。真实结果以对应提交的 GitHub Actions 为准。

## 必须在模拟器或设备完成的验收（尚未人工验收）

- 横屏启动可以看到列车、三名初始伙伴和导航，iPhone / iPad 按钮不被安全区域遮挡。
- 招募星晶正确扣除，角色编入队伍后在战斗场景显示，重新启动后保留。
- 摇杆松手停止；弹出面板、后台、切换场景后无卡住输入。
- 普攻距离外不会扣敌人血；红色预警结束后只对范围内角色生效。
- 切换角色不重置技能冷却；死亡角色不可切入；全灭显示失败。
- 胜利奖励只发一次，撤退不给奖励，再入战斗重新开始第一波。
- 工坊提升攻击；花园和灯塔提升结算收益；升级改变建筑高度，重启后保留。
- 暂停 / 恢复不发生大幅瞬移；录制 10 分钟战斗，观察发热、内存和帧时间。
- 检查存档错误提示，确保损坏文件不会被默认进度覆盖。

## 设计约束

三种原始玩法共用一套队伍与资源：列车负责招募 / 整备，裂界负责战斗 / 产出，
领地负责消耗资源 / 成长。不会另造三个互不关联的游戏。

本版优先验证闭环。大型战争需先建立编队模拟和视距预算；正式角色需要独立 USDZ
模型、骨骼和动画资源。当前方块占位模型和文字面板不代表最终像素漫画视觉品质。
